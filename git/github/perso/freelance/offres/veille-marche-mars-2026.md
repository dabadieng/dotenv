## TJM par niveau d'experience

Junior (0-2 ans) : 380 - 480 euros/jour
Confirme (3-7 ans) : 550 - 750 euros/jour
Expert (8+ ans) : 750 - 1100 euros/jour

Sur Malt, les profils DevOps Azure Terraform se positionnent entre 634 euros/jour (Paris, moyenne) et 700-780 euros/jour pour les profils specialises.

A Lyon : 572 euros/jour en moyenne. A Bordeaux : 558 euros/jour. A Toulouse : 482 euros/jour.

Le marche est en hausse de 5-10% par rapport a 2024.
