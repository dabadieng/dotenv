## Bio

Ingenieure DevOps Azure, j'interviens sur la conception, le deploiement et l'exploitation d'infrastructures cloud complexes.

Mon quotidien chez TotalEnergies : operer une plateforme multi-tenant sur Azure avec 4 environnements (dev, qa, test, prod), 30+ modules Terraform reutilisables et des pipelines CI/CD GitHub Actions automatisees. Je gere le cycle complet, de l'architecture reseau (Front Door Premium, Private Link, WAF, NSG) au deploiement applicatif (Container Apps, AKS, App Service), en passant par les bases de donnees en haute disponibilite (MySQL et PostgreSQL Flexible Server), le monitoring (Application Insights, OpenTelemetry, Dynatrace) et les strategies de backup/DR.

Ce que j'apporte a vos projets :

- Une maitrise de Terraform a l'echelle (400+ fichiers .tf, Building Blocks pattern, drift detection, targeted apply)
- Une expertise Azure Container Apps et AKS (workload profiles, autoscaling, sidecars, Helm)
- Des pipelines CI/CD robustes avec GitHub Actions (OIDC, matrix builds, zero secret)
- Une approche securite-first : Private Link, private endpoints, Key Vault, managed identities, WAF
- L'experience grand compte : process, gouvernance, multi-equipes, conformite

Je suis a l'aise en autonomie sur des perimetre larges comme en renfort ponctuel sur des sujets precis (migration Container Apps, mise en place Front Door, refonte CI/CD, securisation reseau).
